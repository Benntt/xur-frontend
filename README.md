## Deploy
1. `vercel` (link repo)
2. Vercel dashboard → Settings → Environment Variables → add `BUNGIE_API_KEY=7b02fc892682490387e20f1d0cb9ab4c`
3. Push to `main` → GitHub Actions builds → live at `https://YOUR_NAME.github.io/xur-frontend/`
